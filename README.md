# Lesson 10 – Amazon Alexa Sentiment Analysis

This project performs sentiment analysis on Amazon Alexa customer reviews.  

## Dataset
Dataset: [Amazon Alexa Reviews](https://www.kaggle.com/datasets/sid321axn/amazon-alexa-reviews)  
File used: `amazon_alexa.tsv` (3,000 reviews)

## Steps in the Notebook
1. Load and preview the dataset  
2. Visualize feedback distribution and product variations  
3. One-hot encode product variations  
4. Tokenize customer reviews using CountVectorizer  
5. Train a Random Forest Classifier  
6. Evaluate with a confusion matrix and classification report  
7. Display top feature importance  
8. Predict sentiment for a new review

## How to Run
1. Open the notebook in Google Colab  
2. Upload `amazon_alexa.tsv` when prompted  
3. Run all cells from top to bottom
